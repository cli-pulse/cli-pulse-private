CLI Pulse는 AI 코딩 도구의 사용 현황을 한눈에 보여 줍니다. 할당량을 얼마나 썼는지, 언제 리셋되는지, 사용량에 비용이 얼마나 드는지 확인할 수 있습니다. Claude, Codex, Gemini, Cursor, Copilot, OpenRouter, Ollama를 비롯한 수십 개 공급자를 지원하며, Mac뿐 아니라 iPhone, iPad, Apple Watch에서도 볼 수 있습니다.

Mac에서
• 공급자별 할당량과 리셋 시간을 메뉴 막대에서 클릭 한 번으로 확인
• 페이스: 할당량이 리셋 때까지 유지될지, 언제 소진될지 표시
• Claude Code와 Codex 로그로 비용 추정(모든 계산은 Mac에서 처리)
• 공급자별 사용 기록, 활동 히트맵, 비용 예측
• 활성 세션과 최근 세션을 프로젝트별로 표시하고 사용량과 추정 비용도 함께 확인
• 할당량이 얼마 남지 않았을 때, 사용량이나 비용이 급증할 때, 설정한 예산을 넘었을 때 알림
• 비용 보고서를 CSV 또는 PDF로 내보내기
• 펄스 캣: 실제 AI 사용량에 따라 기분이 바뀌는 데스크톱 고양이(선택 사항)
• 계정 없이 사용 가능: 로컬 모드에서는 사용 데이터를 이 Mac에만 보관

iPhone, iPad, Apple Watch에서
• Mac에서 동기화된 할당량, 비용, 세션, 알림을 그대로 확인
• 홈 화면 및 잠금 화면 위젯(Pro)
• Siri 및 단축어: 오늘의 상태나 특정 공급자의 남은 할당량 확인
• Apple Watch: 손목에서 할당량 링, 알림, 세션 확인, 컴플리케이션 지원

iPhone, iPad, Apple Watch에 표시되는 내용은 Mac의 CLI Pulse가 수집한 데이터입니다. Mac에 CLI Pulse를 설치하고 각 기기에서 같은 계정으로 로그인하세요. Mac을 연결하기 전에 '데모 체험'으로 샘플 데이터를 사용해 앱을 살펴볼 수 있습니다.

개인정보 보호
• 공급자 API 키와 세션 로그의 내용은 절대 Mac 밖으로 나가지 않습니다
• 로그인하면 사용 데이터가 암호화된 연결을 통해 CLI Pulse 계정에 동기화됩니다
• 광고 없음, 타사 분석 SDK 없음

무료 및 Pro
CLI Pulse는 공급자 3개까지 무료로 사용할 수 있습니다. CLI Pulse Pro에서는 공급자 수 제한이 없고 홈 화면 및 잠금 화면 위젯을 사용할 수 있습니다.

구독 정보

CLI Pulse Pro는 자동 갱신 구독으로 제공됩니다. 이용 가능한 플랜, 가격, 결제 주기는 구매 시 App Store와 앱에 표시됩니다.

결제 금액은 구매 확인 시 Apple ID 계정으로 청구됩니다. 현재 기간이 끝나기 최소 24시간 전에 자동 갱신을 끄지 않으면 구독이 자동으로 갱신됩니다. 갱신 요금은 현재 기간이 끝나기 전 24시간 이내에 청구됩니다. 구매 후 App Store 계정 설정에서 구독을 관리하고 취소할 수 있습니다.
