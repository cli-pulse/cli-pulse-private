CLI Pulse は、AI コーディングツールをどれだけ使い、いくらかかっているかを確認できるアプリです。Claude、Codex、Gemini、Cursor、Copilot、OpenRouter、Ollama をはじめとする数十のプロバイダーについて、クォータ、リセット時刻、推定コストを Mac で確認でき、iPhone、iPad、Apple Watch でも見ることができます。

Mac では
・各プロバイダーのクォータとリセット時刻を、メニューバーからワンクリックで確認
・ペース：リセットまでクォータがもつか、あとどれくらいで使い切るかを表示
・Claude Code と Codex のログから推定コストを算出。計算はすべて Mac 上で行われます
・プロバイダーごとの使用履歴、アクティビティのヒートマップ、コスト予測
・実行中と最近のセッションをプロジェクト別に表示し、使用量と推定コストも確認
・クォータが残り少なくなったとき、使用量やコストが急増したとき、設定した予算を超えたときにアラートを表示
・コストレポートを CSV または PDF で書き出し
・パルスキャット：実際の AI の使用状況に合わせて気分が変わる、オプションのデスクトップ猫
・アカウントは不要：ローカルモードでは、使用状況のデータはこの Mac から外に出ません

iPhone、iPad、Apple Watch では
・Mac から同期された、同じクォータ、コスト、セッション、アラートを確認
・ホーム画面とロック画面のウィジェット（Pro）
・Siri とショートカット：今日の状況や、特定のプロバイダーの残りクォータを確認
・Apple Watch：クォータのリング、アラート、セッションを手首で確認。コンプリケーションにも対応

iPhone、iPad、Apple Watch に表示されるのは、Mac の CLI Pulse が収集したデータです。Mac に CLI Pulse をインストールし、各デバイスで同じアカウントにサインインしてください。Mac を接続する前に、「デモを試す」でサンプルデータを使ってアプリを試せます。

プライバシー
・プロバイダーの API キーとセッションログの内容が Mac の外に出ることはありません
・サインインすると、使用状況のデータが暗号化された接続で CLI Pulse アカウントに同期されます
・広告なし、他社製の分析 SDK なし

無料版と Pro
CLI Pulse は 3 つのプロバイダーまで無料で使えます。CLI Pulse Pro では、プロバイダーの数が無制限になり、ホーム画面とロック画面のウィジェットも使えるようになります。

サブスクリプションについて

CLI Pulse Pro は自動更新サブスクリプションです。利用できるプラン、価格、請求期間は、購入時に App Store とアプリ内に表示されます。

お支払いは購入の確定時に Apple ID アカウントに請求されます。現在の期間が終了する 24 時間前までに自動更新をオフにしない限り、サブスクリプションは自動的に更新されます。更新料金は、現在の期間が終了する前の 24 時間以内に請求されます。サブスクリプションは、購入後に App Store のアカウント設定で管理およびキャンセルできます。
