你的 iPhone 又能操作 Mac 上的 CLI 会话了 —— 这次走的是你自己的局域网,不经过服务器。

• 新增:远程操作。在同一个 Wi-Fi 下,iPhone 会找到你的 Mac,配对一次之后就能列出上面正在运行的 CLI 会话。你可以实时看会话的终端、直接打字、启动和停止会话,以及在手机上批准或拒绝工具权限请求。连接在两台设备之间直连并加密,会话输出不经过我们的服务器。

它替代的是 1.52.1 里移除的那套基于服务器的实现 —— 那套已经不能用了。远程操作需要 Mac 上运行 Developer ID 版本的 CLI Pulse;Mac 的 App Store 版本会直接说明这一点,而不是给你一个按了也没用的开关。

• 修复:远程终端打开是黑的。第一屏内容在终端视图存在之前就被推送,然后被静默丢弃,于是一个已经打印过横幅的会话在下次输出之前什么都不显示。

• 修复:打开会话终端时,恰好关掉了那个终端正在使用的连接,导致画面只绘制一次就不动了。

• 修复:把 app 切回前台时会重新建立连接。此前切到后台会断开连接,而没有任何地方去重连。

• 修复:密钥可能以明文发到手机上。当输出在一个 token 中间停顿时,已经缓存的那部分会不经脱敏直接发出 —— 而 API key 的尾部恰恰承载了它大部分的熵。

• 修复:已经回答过的审批仍然占着名额,于是长会话最终会完全无法再发起权限请求。

• 修复:helper 已经停止的会话,键盘仍然是活的,而且用一条未翻译的内部错误回应你的按键。
