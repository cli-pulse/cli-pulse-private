CLI Pulse 现在会先征求你的同意，再读取 30 天前的会话日志；Codex 积分现在也会显示剩余积分数。

• 更早的日志改为单独询问。每次刷新读取最近 30 天的会话日志；为了补全用量历史，CLI Pulse 还可以一次性读取最多一年的旧日志。以前的版本不经询问就会这样读取一次，而 1.50 至 1.54 版的询问只提到 30 天。现在首次询问时，「开始本地扫描」包括这次一次性读取，「仅最近 30 天」则不包括。如果你之前已同意扫描，或者已登录但从未被问过，CLI Pulse 会就更早的日志询问你一次。无论选哪个，最近 30 天的扫描都照常进行；「仅最近 30 天」不会删除这台 Mac 上已生成的用量历史；登录状态下，之后可以在「设置 › 隐私 › 包括更早的用量历史」中更改。

• 日常扫描不再打开 30 天内没有更新过的 Claude Code 日志。

• 如果你选了「暂时不要」且已登录，「设置 › 隐私」中现在提供「重新选择…」，可以再次显示这个问题。以前只能退出登录才能重新选择。

• Codex 积分：有积分的账户现在会把余额显示为「剩余 N 积分」。这台 Mac 一旦看到某个账户有积分，余额用完后也会继续显示「剩余 0 积分」。对于从未有过积分的账户，这台 Mac 不会添加「积分」这一行。

• Codex 的配额窗口按时长命名，只有每周限额的账户不会再被标成「5h 窗口」。每周限额用完后，5 小时进度条、卡片和菜单栏都会显示剩余 0%，并给出每周限额的重置时间。5 小时窗口的节奏标记现在按 5 小时计算，不再按一周。

• 「隐藏个人信息」（设置 › 高级）现在也会隐藏邮箱形式的账户标签，在卡片、账户行和设置中显示为「账户 1」「账户 2」等。

• Gemini：Google 已停止为个人 Google 账户提供 Gemini CLI。这类账户现在显示「已停止支持个人账户」并说明原因，不再显示「认证失败」并建议重新连接。

• 由子代理或工作流运行的 Claude Code 会话，在「会话」中显示所属项目的名称，不再显示「subagents」或运行 ID。

• 用量仪表盘的总额改为「预估总费用」，并加注一行：费用是以 API 按量付费价格算出的预估值，不是真实账单。token 的帮助说明写明了各服务商分别统计什么；一条拿这些数字与其他 App 对比、但并不准确的提示已删除。

• 概览不再显示空的「主要项目」卡片，登录状态下也不再显示始终为 0 的「请求数」。「费用概览」不再为只报告配额的服务商列出费用为 0 的行，「试用演示」也只显示真实账户可能有的内容。

• Yield Score 卡片不再让你去打开这台 Mac 上看不到的设置，在「试用演示」中会隐藏，退出登录后也会消失。

• 修复：浅色模式下，活动热力图中没有用量的日子也能看清了，用量最多的日子颜色最深；数字按千位分组（15,531，而不是 15531）；底部的语言地球图标变小并改为灰色；浅淡的文字更易阅读。

• 用语：配额告警的标题加上了「配额」二字；告警数量徽章改为「3 条警告」「严重级 1 条」；脉冲猫的「用量食谱（7 天）」改为「饮食组成（近 7 天）」。
