CLI Pulse 现在把 Codex 积分显示为余额，读取超过 30 天的旧日志前也会先征求你的同意。选择「暂时不要」或退出登录后，后台同步和最新版 Companion CLI 都会停止。

• Codex 积分：有积分的账户现在显示「剩余 N 积分」。这台 Mac 一旦检测到某个账户有积分，余额用完后也会继续显示「剩余 0 积分」。对于从未有过积分的账户，这台 Mac 不会添加「积分」这一行。

• 用量仪表盘的总额改为「预估总费用」：这是以 API 按量付费价格算出的预估值，不是真实账单。

• 更早的日志改为单独询问。每次刷新读取最近 30 天的会话日志；为了补全用量历史，CLI Pulse 还可以一次性读取最多一年的旧日志。以前的版本不经询问就会这样读取一次，而 1.50 至 1.54 版的询问只提到 30 天。如果你之前已同意扫描，或者已登录但从未被问过，CLI Pulse 会就更早的日志询问你一次。无论选哪个，最近 30 天的扫描都照常进行；「仅最近 30 天」不会删除已生成的用量历史；之后可以在「设置 › 隐私 › 包括更早的用量历史」中更改。

• 在已同步到账户的 Mac 上，「暂时不要」现在也会生效；1.50 至 1.54 版即使在你选了「暂时不要」之后，仍会照常读取和同步。如果你已登录且当前的选择是「暂时不要」，「设置 › 隐私」中现在会提供「重新选择…」；以前必须先退出登录才能重新选择。在本地模式下，设置中现在也会显示「隐私」和「Companion CLI」。

• 后台同步现在遵循你的选择和账户：选择「暂时不要」或退出登录后，它不读取也不发送任何内容；它只会同步到 App 当前登录的账户。「设置 › 高级」会显示它是否已暂停；如果显示「需要重启」，请关闭后台同步再重新打开。最新版 Companion CLI 也遵循同样的规则；旧版本如果不遵循，App 会提示你。

• 对于 Cookie 来源设为「自动」的服务商，严格隐私模式现在也会阻止 CLI Pulse 从浏览器导入 Cookie；这类服务商会显示「严格隐私模式下不读取」，而不是报错。严格隐私模式和「跳过 Claude Code 钥匙串访问」现在也适用于后台同步和最新版 Companion CLI。

• 崩溃报告不再包含网址中的查询参数。

• 「隐藏个人信息」现在也会把邮箱形式的账户标签显示为「账户 1」「账户 2」等。

• Gemini：Google 已停止为个人 Google 账户提供 Gemini CLI。这类账户现在显示「已停止支持个人账户」并说明原因，不再显示「认证失败」。

• Codex 的配额窗口现在按时长命名，只有每周限额的账户不会再被标成「5h 窗口」。每周限额用完后，5 小时进度条和卡片会显示剩余 0% 及每周限额的重置时间，菜单栏也会显示剩余 0%。5 小时窗口的节奏标记现在按 5 小时计算，不再按一周。

• 用量历史会保留日志已被删除的用量。Claude Code 默认会删除 30 天前的日志；重新读取较早的日期时，历史中已有的某一天会保留这次读取完全没找到的服务商用量；如果读到的 Claude 用量更少，也会保留原来的数值。

• 由子代理或工作流运行的 Claude Code 会话，现在会在「会话」中显示所属项目的名称。

• 概览不再显示空的「主要项目」卡片，在已同步到账户的 Mac 上也不再显示始终为 0 的「请求数」。「费用概览」不再为只报告配额的服务商列出费用为 0 的行，「试用演示」也只显示真实账户可能有的内容。

• 修复：Yield Score 卡片不再让你去打开这台 Mac 上看不到的设置，退出登录后也会消失；浅色模式下，活动热力图中没有用量的日子也能看清了；数字加上了千位分隔符（15,531，而不是 15531）；颜色较浅的文字更易阅读。

• 用语：配额告警的标题加上了「配额」二字；告警数量徽章改为「3 条警告」「1 条严重告警」；脉冲猫的「用量食谱（7 天）」改为「饮食组成（近 7 天）」。
