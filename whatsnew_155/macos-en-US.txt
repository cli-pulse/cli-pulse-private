CLI Pulse now shows Codex credits as a balance and asks before reading logs older than 30 days. "Not now" and signing out now also stop background sync and an up-to-date Companion CLI.

• Codex credits: an account with credits now shows "N credits left". Once this Mac has seen credits on an account, a spent balance stays as "0 credits left". Accounts that never had credits get no Credits row from this Mac.

• The Usage Dashboard's total is now "Est. Total Cost": an estimate at API pay-as-you-go prices, not a bill. Token help texts say what each provider counts, and an inaccurate tooltip comparing them with another app is gone.

• Older logs are now their own question. Each refresh reads the last 30 days of session logs; CLI Pulse can also read up to a year of older logs once, to fill in your history. Earlier versions did that without asking, and the question in 1.50 to 1.54 mentioned only 30 days. If you said yes to the scan, or are signed in and were never asked, CLI Pulse asks you once about them. Either answer keeps the 30-day scan, "Last 30 days only" deletes no history, and Settings › Privacy › "Include older usage history" changes it later.

• If you chose "Not now" while signed in, Settings › Privacy now offers "Choose again…"; before, you had to sign out. In local mode, Settings now shows Privacy and Companion CLI too.

• Background sync now follows your answer and your account: after "Not now" or a sign-out it reads and sends nothing, and it syncs only to the account the app is signed in to. Settings › Advanced shows when it is paused; if it says "Restart needed", turn it off and on again. An up-to-date Companion CLI follows them too; if an older one does not, the app says so.

• Strict privacy mode now also stops CLI Pulse from importing browser cookies for providers set to "Automatic", which then read "Not read in Strict privacy mode" instead of an error. It and "Skip Claude Code keychain access" now also apply to background sync and an up-to-date Companion CLI. Crash reports leave out the query part of web addresses.

• Hide personal information now also replaces account labels that are email addresses with "Account 1", "Account 2" and so on.

• Gemini: Google no longer offers Gemini CLI to personal accounts, which now read "Ended for personal accounts" with the reason instead of "Authentication failed".

• Codex limits are named by their length, so a weekly-only limit is no longer "5h Window". With the weekly limit used up, the 5-hour bar, the card and the menu bar read 0% left with the weekly reset. The 5-hour pace marker now counts 5 hours, not a week.

• Usage history keeps usage whose logs are gone. Claude Code deletes its logs after 30 days by default; when older days are read again, a day keeps a provider's usage the read finds none of, and its Claude usage if the read finds less.

• Claude Code sessions run by subagents or workflows show their project's name in Sessions.

• The Overview no longer shows an empty Top Projects card or, while signed in, a Requests count that always read 0. Cost Summary drops zero-cost rows for quota-only providers, and Try Demo shows only what a real account can have.

• Fixes: the Yield Score card no longer asks for a setting this Mac doesn't show and goes away when you sign out; the light-mode heatmap shows days with no usage; counts are grouped (15,531); faint text is easier to read; Pulse Cat's "Hunger" is now "Fullness"; quota badges read "RUNNING LOW".
