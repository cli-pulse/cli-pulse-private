이제 CLI Pulse는 Codex 크레딧을 잔액으로 표시하고, 30일보다 오래된 로그를 읽기 전에 먼저 묻습니다. '지금은 안 함'을 선택하거나 로그아웃하면 백그라운드 동기화와 최신 Companion CLI가 중지됩니다.

• Codex 크레딧: 크레딧이 있는 계정에는 이제 'N 크레딧 남음'이 표시됩니다. 이 Mac이 한 번이라도 크레딧을 확인한 계정에는 크레딧을 다 쓴 뒤에도 '0 크레딧 남음'이 계속 표시됩니다. 크레딧이 한 번도 없었던 계정에는 이 Mac이 '크레딧' 행을 추가하지 않습니다.

• 사용량 대시보드의 합계가 '추정 총 비용'으로 바뀌었습니다. API 종량제 요금으로 계산한 추정치이며 청구액이 아닙니다.

• 이전 로그를 읽을지는 이제 따로 묻습니다. 새로고침할 때마다 최근 30일 치 세션 로그를 읽습니다. 사용 기록을 채우기 위해 CLI Pulse는 최대 1년 치의 이전 로그를 한 번만 읽을 수도 있습니다. 예전 버전은 묻지 않고 이렇게 읽었고, 1.50~1.54 버전의 질문도 30일만 언급했습니다. 이미 스캔을 허용했거나, 로그인되어 있지만 질문을 받은 적이 없다면 이전 로그에 대해 한 번 묻습니다. 어느 쪽을 선택하든 최근 30일 스캔은 계속되고, '최근 30일만'을 선택해도 이미 만들어진 사용 기록은 지워지지 않으며, 로컬 모드나 계정에 동기화된 Mac에서는 나중에 설정 › 개인정보 보호 › '이전 사용 기록 포함'에서 바꿀 수 있습니다.

• 이제 계정에 동기화된 Mac에서도 '지금은 안 함'이 적용됩니다. 1.50~1.54 버전은 '지금은 안 함'을 선택해도 계속 읽고 동기화했습니다. 이런 Mac에서는 설정 › 개인정보 보호에 '다시 선택…'이 표시됩니다. 이전에는 로그아웃하는 방법밖에 없었습니다. 로컬 모드에서도 이제 설정에 개인정보 보호와 Companion CLI가 표시됩니다.

• 백그라운드 동기화가 이제 사용자의 선택과 계정을 따릅니다. '지금은 안 함'을 선택하거나 로그아웃하면 아무것도 읽거나 보내지 않으며, 앱이 로그인한 계정으로만 동기화합니다. 일시정지 여부는 설정 › 고급에 표시되며, '다시 시작 필요'가 표시되면 백그라운드 동기화를 껐다가 다시 켜세요. 최신 Companion CLI도 이를 따르며, 이전 버전이 따르지 않으면 앱이 알려 줍니다.

• 엄격한 개인정보 보호 모드는 이제 쿠키 소스가 '자동'인 공급자에 대해 브라우저에서 쿠키를 가져오는 것도 막으며, 이런 공급자에는 오류 대신 '엄격한 개인정보 보호 모드에서는 읽지 않음'이 표시됩니다. 이 모드와 'Claude Code 키체인 접근 건너뛰기'는 이제 백그라운드 동기화와 최신 Companion CLI에도 적용됩니다.

• 충돌 리포트에는 웹 주소의 쿼리 부분이 더 이상 포함되지 않습니다.

• '개인정보 숨기기'가 이제 이메일 주소로 된 계정 라벨도 '계정 1', '계정 2'처럼 바꿔 표시합니다.

• Gemini: Google이 개인 계정에 대한 Gemini CLI 제공을 중단했으므로, 이런 계정에는 '인증 실패' 대신 '개인 계정 지원 종료'와 그 이유를 표시합니다.

• 이제 Codex 할당량 기간에 길이에 따라 이름을 붙이므로, 주간 한도만 있는 계정이 더 이상 '5h 기간'으로 표시되지 않습니다. 주간 한도를 다 쓰면 5시간 막대와 카드는 '0% 남음'과 주간 리셋 시간을, 메뉴 막대는 '0% 남음'을 표시합니다. 5시간 페이스 마커도 이제 일주일이 아니라 5시간을 기준으로 표시됩니다.

• 사용 기록은 로그가 삭제된 날의 사용량도 유지합니다. Claude Code는 기본적으로 30일이 지난 로그를 삭제합니다. 지난 날짜를 다시 읽을 때, 기록에 있는 날은 읽기에서 전혀 찾지 못한 공급자의 사용량을 그대로 두고, Claude 사용량은 읽은 값이 더 적으면 기존 값을 유지합니다.

• 하위 에이전트나 워크플로가 실행한 Claude Code 세션은 '세션'에서 프로젝트 이름으로 표시됩니다.

• 개요에 빈 '상위 프로젝트' 카드와, 계정에 동기화된 Mac에서 항상 0이던 '요청'이 더 이상 표시되지 않습니다. '비용 요약'은 할당량만 보고하는 공급자의 비용이 0인 행을 빼고, '데모 체험'은 실제 계정에 있을 수 있는 내용만 보여 줍니다.

• 수정: Yield Score 카드는 이 Mac에 보이지 않는 설정을 켜라고 더 이상 요청하지 않으며, 로그아웃하면 사라집니다. 라이트 모드의 활동 히트맵에서 사용 기록이 없는 날도 잘 보입니다. 숫자는 세 자리마다 쉼표로 구분됩니다(15531이 아니라 15,531). 흐린 글자는 더 읽기 쉬워졌습니다.

• 표현: 펄스 캣의 '허기'가 '포만감'으로 바뀌었습니다(100%는 배가 가득 찼다는 뜻입니다). 사용량 대시보드의 '최대 사용일'은 '일 최대 사용량'이 되었고, 계정 제거 확인 문구를 가려진 계정 이름도 자연스럽게 읽히도록 고쳤습니다.
