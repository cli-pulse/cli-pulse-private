CLI Pulse 現在把 Codex 點數顯示為餘額，並會在讀取 30 天前的日誌之前先徵求你的同意。選擇「暫時不要」或登出後，背景同步和最新版 Companion CLI 現在也會停止。

• Codex 點數：有點數的帳號現在顯示「剩餘 N 點數」。這台 Mac 一旦看到某個帳號有點數，餘額用完後也會繼續顯示「剩餘 0 點數」。對於從未有過點數的帳號，這台 Mac 不會加上「點數」這一列。

• 用量儀表板的總額改為「預估總費用」：這是以 API 按用量計費的價格估算的金額，並非實際帳單。token 的說明文字寫明了各服務商分別計算哪些內容；一則與其他 App 比較、且並不準確的提示已移除。

• 更早的日誌改為單獨詢問。每次重新整理會讀取最近 30 天的工作階段日誌；為了補齊用量歷史，CLI Pulse 也可以讀取一次最多一年份的舊日誌。先前的版本沒有詢問就會這樣讀取一次，而 1.50 至 1.54 版的詢問只提到 30 天。如果你先前已同意掃描，或是已登入但從未被問過，CLI Pulse 會針對更早的日誌詢問你一次。無論選哪個，最近 30 天的掃描都會照常進行；「僅限最近 30 天」不會刪除已建立的用量歷史；之後可以在「設定 › 隱私 › 包含更早的用量歷史」中更改。

• 如果你在登入時選了「暫時不要」，「設定 › 隱私」現在會提供「重新選擇…」；先前只能登出才能重新選擇。在本機模式下，設定中現在也會顯示「隱私」和「Companion CLI」。

• 背景同步現在會遵循你的選擇和帳號：選擇「暫時不要」或登出後，它不會讀取也不會傳送任何內容；它只會同步到 App 目前登入的帳號。「設定 › 進階」會顯示它是否已暫停；如果顯示「需要重新啟動」，請關閉背景同步再重新開啟。最新版 Companion CLI 也會遵循；如果舊版本不遵循，App 會告訴你。

• 嚴格隱私模式現在也會阻止 CLI Pulse 為 Cookie 來源設為「自動」的服務商從瀏覽器匯入 Cookie，這類服務商會顯示「嚴格隱私模式下不讀取」，而不是錯誤。嚴格隱私模式和「略過 Claude Code 鑰匙圈存取」現在也適用於背景同步和最新版 Companion CLI。當機報告不再包含網址中的查詢部分。

• 「隱藏個人資訊」現在也會把電子郵件形式的帳號標籤顯示為「帳號 1」「帳號 2」等。

• Gemini：Google 已停止為個人 Google 帳號提供 Gemini CLI。這類帳號現在會顯示「已停止支援個人帳號」並說明原因，不再顯示「驗證失敗」。

• Codex 的配額時段依時長命名，只有每週限額的帳號不會再被標成「5h 時段」。每週限額用完後，5 小時進度條、卡片和選單列都會顯示剩餘 0%，並顯示每週限額的重置時間。5 小時時段的節奏標記現在依 5 小時計算，不再依一週。

• 用量歷史會保留日誌已被刪除的用量。Claude Code 預設會刪除 30 天前的日誌；重新讀取較早的日期時，歷史中已有的某一天會保留這次讀取完全沒找到的服務商用量；如果讀到的 Claude 用量較少，也會保留原本的數值。

• 由子代理或工作流程執行的 Claude Code 工作階段，會在「工作階段」中顯示所屬專案的名稱。

• 概覽不再顯示空白的「高用量專案」卡片，登入時也不再顯示一律為 0 的「請求數」。「費用概覽」不再為只回報配額的服務商列出費用為 0 的列，「試用示範模式」也只顯示真實帳號可能有的內容。

• 修正：Yield Score 卡片不再要你開啟這台 Mac 上看不到的設定，登出後也會消失；淺色模式下，活動熱度圖中沒有用量的日子現在也看得清楚；數字以千位分隔（15,531，而不是 15531）；較淡的文字更容易閱讀。

• 用語：配額警示的標題加上了「配額」二字；警示數量徽章改為「3 則警告」「嚴重級 1 則」；用量儀表板的「尖峰單日」改為「單日尖峰」；脈衝貓的「用量食譜（7 天）」改為「飲食組成（近 7 天）」。
