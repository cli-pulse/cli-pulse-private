CLI Pulse 現在讀取 30 天以前的工作階段日誌前，會先徵求你的同意；Codex 點數也改為以點數顯示。

• 更早的日誌改為單獨詢問。每次重新整理會讀取最近 30 天的工作階段日誌；為了補齊用量歷史，CLI Pulse 也可以讀取一次最多一年份的舊日誌。先前的版本沒有詢問就會這樣讀取一次，而 1.50 至 1.54 版的詢問只提到 30 天。現在首次詢問時，「開始本機掃描」包含這次一次性的讀取，「僅限最近 30 天」則不包含。如果你先前已同意掃描，或是已登入但從未被問過，CLI Pulse 會針對更早的日誌詢問你一次。無論選哪個，最近 30 天的掃描都會照常進行；「僅限最近 30 天」不會刪除這台 Mac 上已建立的用量歷史；之後可以在「設定 › 隱私 › 包含更早的用量歷史」中更改。

• 例行掃描不再開啟最後寫入時間在 30 天以前的 Claude Code 日誌。

• 如果你選了「暫時不要」且已登入，「設定 › 隱私」現在會提供「重新選擇…」，可以再次顯示這個問題。先前唯一的方法是登出。

• Codex 點數：有點數的帳號會把餘額顯示為「剩餘 N 點數」，而不是「剩餘 100%」。這台 Mac 一旦看到某個帳號有點數，餘額用完後也會繼續顯示「剩餘 0 點數」。對於從未有過點數的帳號，這台 Mac 不會加上「點數」這一列。

• Codex 的配額時段依時長命名，只有每週限額的帳號不會再被標成「5h 時段」。每週限額用完後，5 小時進度條、卡片和選單列都會顯示剩餘 0%，並顯示每週限額的重置時間；5 小時時段的節奏標記也依 5 小時而不是一週來定位。

• 「隱藏個人資訊」（設定 › 進階）現在也會隱藏電子郵件形式的帳號標籤，在卡片、帳號列和設定中顯示為「帳號 1」「帳號 2」等。

• Gemini：Google 已停止為個人 Google 帳號提供 Gemini CLI。這類帳號現在會顯示「已停止支援個人帳號」並說明原因，不再顯示「驗證失敗」並建議重新連線。

• 由子代理或工作流程執行的 Claude Code 工作階段，會在「工作階段」中顯示所屬專案的名稱，不再顯示「subagents」或執行 ID。

• 用量儀表板的總額改為「預估總費用」，並加註一行：費用以 API 按用量計費的價格估算，並非實際帳單。token 的說明文字寫明了各服務商計算的內容；一則與其他 App 比較、且並不準確的提示已移除。

• 概覽不再顯示空白的「高用量專案」卡片，登入時也不再顯示一律為 0 的「請求數」。「費用概覽」不再為只提供配額的服務商列出費用為 0 的列，「試用示範模式」也只顯示真實帳號可能有的內容。

• Yield Score 卡片不再要你開啟這台 Mac 上看不到的設定，在「試用示範模式」中會隱藏，登出後也會消失。

• 修正：淺色模式下，活動熱度圖的空白日期清楚可見，用量最多的日子顏色最深；數字以千位分隔（15,531，而不是 15531）；底部的語言地球圖示變小並改為灰色；較淡的文字更容易閱讀。

• 用語：配額警示的標題會寫明「配額」；警示數量徽章改為「3 則警告」「嚴重級 1 則」；用量儀表板的「尖峰單日」改為「單日尖峰」，脈衝貓的「用量食譜（7 天）」改為「飲食組成（近 7 天）」。
