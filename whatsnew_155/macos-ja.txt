CLI Pulse は Codex のクレジットを残高で表示し、30 日より古いログを読み取る前に確認するようになりました。「今はしない」を選んだときやサインアウトしたときは、バックグラウンド同期と最新の Companion CLI が停止します。

・Codex のクレジット：クレジットのあるアカウントは「残り N クレジット」と表示されます。この Mac でクレジットを確認したことのあるアカウントは、使い切った後も「残り 0 クレジット」と表示されます。クレジットを持ったことのないアカウントには、この Mac は「クレジット」の行を追加しません。

・使用状況ダッシュボードの合計は「推定総コスト」になりました。API の従量課金料金で算出した推定額で、請求額ではありません。

・古いログを読み取るかどうかは、別途確認するようになりました。更新のたびに読み取るのは直近 30 日分のセッションログです。使用履歴を補完するため、CLI Pulse は最大 1 年分の古いログを一度だけ読み取ることもできます。以前のバージョンは確認せずにこの読み取りを行っており、1.50〜1.54 の確認画面も 30 日分にしか触れていませんでした。すでにスキャンを許可していた場合や、サインイン中でまだ質問されていない場合は、古いログについて一度だけ確認します。どちらを選んでも直近 30 日のスキャンは続き、「直近 30 日のみ」を選んでも作成済みの使用履歴は削除されません。回答はあとから「設定 › プライバシー › 古い使用履歴も含める」で変更できます。

・アカウントと同期している Mac でも「今はしない」が適用されるようになりました。1.50〜1.54 では、「今はしない」を選んでもアプリが読み取りと同期を続けていました。サインイン中で回答が「今はしない」の場合は、「設定 › プライバシー」に「選び直す…」が表示されるようになりました。これまではサインアウトするしかありませんでした。ローカルモードでも、設定に「プライバシー」と「Companion CLI」が表示されるようになりました。

・バックグラウンド同期は、確認への回答とアカウントに従うようになりました。「今はしない」を選んだときやサインアウトしたときは何も読み取らず、何も送信しません。同期先は、アプリがサインインしているアカウントだけです。一時停止中かどうかは「設定 › 詳細」に表示され、「再起動が必要」と表示された場合は、バックグラウンド同期をオフにしてから、もう一度オンにしてください。最新の Companion CLI も同じように従います。古いバージョンが従わない場合は、アプリでお知らせします。

・プライバシー強化モードは、Cookie ソースが「自動」のプロバイダーについて、ブラウザから Cookie を読み込むことも止めるようになりました。該当するプロバイダーには、エラーではなく「プライバシー強化モード中は読み取りません」と表示されます。このモードと「Claude Code のキーチェーンにアクセスしない」は、バックグラウンド同期と最新の Companion CLI にも適用されます。

・クラッシュレポートには Web アドレスのクエリ部分を含めなくなりました。

・「個人情報を非表示」（旧称「個人情報を隠す」）が、メールアドレス形式のアカウントラベルも「アカウント 1」「アカウント 2」のように置き換えるようになりました。

・Gemini：Google が個人アカウント向けに Gemini CLI の提供を終了したため、該当するアカウントには「認証に失敗」ではなく、「個人アカウント向けの提供は終了」とその理由を表示します。

・Codex のクォータの期間を長さに応じて命名するようになり、週次の上限しかないアカウントが「5h」と表示されることはなくなりました。週次の上限を使い切ると、5 時間のバーとカードは残り 0% と週次のリセット時刻を、メニューバーは残り 0% を表示します。5 時間のペースマーカーは、1 週間ではなく 5 時間を基準に表示されるようになりました。

・使用履歴は、ログが削除された分の使用量も保持するようになりました。Claude Code は初期設定で 30 日を過ぎたログを削除します。過去の日を読み直したとき、履歴にある日は、読み取りでまったく見つからなかったプロバイダーの使用量をそのまま保持し、Claude の使用量は読み取った値のほうが少なければ元の値を保持します。

・サブエージェントやワークフローが実行した Claude Code のセッションは、「セッション」にプロジェクト名が表示されるようになりました。

・概要に空の「上位プロジェクト」カードを表示しなくなり、アカウントと同期している Mac で常に 0 だった「リクエスト」も表示しなくなりました。「コスト概要」はクォータしか報告しないプロバイダーのコスト 0 の行を省き、「デモを試す」では、実際のアカウントにありうる内容だけを表示します。

・修正：Yield Score のカードは、この Mac に表示されない設定をオンにするよう求めなくなり、サインアウトすると消えます。ライトモードでは、アクティビティのヒートマップ上の使用のない日も見分けられるようになりました。数値は桁区切りで表示します（15531 ではなく 15,531）。薄い文字が読みやすくなりました。クォータのアラートの見出しに「クォータ」と明記するようになりました（例：「Codex の『週次』クォータが 80% に到達」）。
