## What 1.63.3 is

1.63.2 plus #797 to #799, all found while shipping 1.63.2.

## Claude

- **#798: a refused Claude Code sign-in no longer reads "This one is on us".**
  On 1.63.2 the Claude row said "Check failed — This one is on us — the check
  couldn't be completed. An update will fix it." whenever every source
  failed, because the collector's failure categories did not know Claude's
  errors and the resolver reported the last source's failure. Now:
  - when OAuth could not use Claude Code's login on this Mac (refused,
    expired, or the keychain dialog declined) and every other failure can be
    put down to that login, the row says "Not signed in" or "Keychain access
    declined", as it already did when no other source could run;
  - otherwise the most actionable failure is reported: a refused token or
    claude.ai cookie is "Authentication failed", a rate limit or error status
    "Check failed" ("The provider returned an error. It usually clears on its
    own.");
  - the collector error log keeps the failure the run actually ended with.
  The LoginItem helper reports its own collector status and is unchanged.

## Menu-bar window

- **#799: Refresh Cadence fits Settings.** Settings › General › Refresh
  Cadence is a menu beside its label, like Currency. The six-segment picker it
  replaces measured 324-335 pt against about 356 pt inside the window and ran
  past the right edge.
