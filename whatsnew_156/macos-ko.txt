Codex 추정 비용이 높아지고 Claude 추정치가 달라지며, 설정 › 고급은 이제 이 Mac이 계정에 동기화되지 않아도 표시됩니다.

• Codex 추정 비용이 높아집니다. 이전에는 빠져 있던 하위 에이전트 세션도 이제 집계합니다. 두 파일로 나뉜 Codex 스레드 중 한 파일이 누락되지 않으며, 하위 에이전트가 상위 세션에서 복사해 온 기록은 다시 집계하지 않습니다. 포크한 세션과 일부 하위 에이전트 세션은 간소화한 규칙으로 집계하므로, 복사된 마지막 요청이 한 번 더 집계될 수 있습니다. '세션'에서는 실행 중인 Codex 하위 에이전트가 이제 별도의 세션으로 표시됩니다.

• 각 Codex 요청을 해당 모델에 대해 OpenAI가 요청 당일에 공개한 API 요금으로 계산하며, OpenAI가 롱 컨텍스트 요금을 공개한 모델에서는 입력이 272K 토큰을 넘는 요청에 그 요금을 적용합니다. 요금 변경은 변경일부터 적용되고, gpt-5.5, gpt-5.6-sol 같은 새 모델은 gpt-5.4의 요금이 아니라 각자의 요금으로 계산됩니다.

• 아직 자체 요금이 없어 같은 계열 모델의 단가로 계산한 모델이 포함된 수치는 이제 '≈$…'로 표시되고, 비용 카드에는 '근사치' 배지가 표시됩니다.

• 지난 Codex 사용량을 다시 집계합니다. 이전 로그 읽기를 허용했다면 CLI Pulse는 최대 1년 치 Codex 로그를 다시 읽어 사용 기록의 지난 날짜를 새 규칙으로 다시 집계하고, 로그인되어 있으면 계정에 있는 이 Mac의 이전 Codex 수치도 갱신하므로 iPhone에도 새 수치가 표시됩니다. Codex 사용량 집계 방식이 업데이트로 바뀔 때마다 이 작업을 다시 한다는 점은 동의 화면과 설정 › 개인정보 보호에도 안내되어 있습니다. 로그가 없어진 날은 기존 수치가 유지됩니다.

• 사용량 대시보드는 이제 Codex의 캐시 입력을 한 번만 집계합니다. 캐시 입력은 원래 Codex 입력에 포함되는데 그동안 한 번 더 더해졌기 때문에, 여기의 Codex 토큰 합계가 실제보다 많게 표시되었습니다. 이 Mac에 이전부터 Codex 사용량이 있었다면 개요에 바뀐 점을 설명하는 카드가 나타나고, 대시보드에는 어느 날짜까지의 수치가 이전 방식으로 집계되었는지 표시됩니다.

• CLI Pulse가 이제 Anthropic이 해당 날짜에 공개한 요금으로 Claude를 계산하고, Claude Opus 5.5, Claude Fable 5.1, Claude Sonnet 5.5에는 각자의 요금을, 1시간 캐시 쓰기에는 그 요금을, Sonnet 5에는 현재 요금을 적용하며, 각 응답을 마지막 줄 기준으로 한 번만 집계하므로, Claude 추정 비용도 모델에 따라 내려가기도 하고 올라가기도 합니다.

• 업데이트 후 처음 새로고침할 때 최근 30일 치 Claude와 Codex 로그를 한 번 다시 읽어 새 방식으로 집계합니다.

• 설정 › 고급이 이제 로컬 모드에서도, 이 Mac이 아직 계정에 동기화되지 않았을 때도 표시되며, 백그라운드 동기화와 그 상태, 'CLI 도구 접근', '개인정보 숨기기'가 포함됩니다. 로컬 모드에서는 아무것도 업로드하지 않는다고 안내합니다. 로그아웃한 상태에서는 '로그인 시 시작'과 백그라운드 동기화가 표시되고, 백그라운드 동기화가 켜져 있으면 상태가 '일시정지됨: 로그아웃됨'으로 표시됩니다. 백그라운드 동기화를 끄면 더 이상 지난 상태를 표시하지 않습니다.

• Gemini: 공급자 설정에서 작동하지 않는 Google 로그인을 더 이상 제공하지 않으며, Gemini CLI 로그인이 만료되면 CLI Pulse에서 다시 연결하라고 하는 대신 '세션 만료됨(다시 로그인 필요)'을 표시합니다.

• 수정: 계정에 동기화된 Mac에서 키체인이 잠겨 있을 때 새로고침하면 이 Mac의 사용량을 한 번 더 보내던 문제를 고쳤습니다(iPhone에서는 이를 두 번 집계했습니다). 공급자 전체 '할당량' 막대는 남은 비율만큼 채워지며, '데모 체험'은 실제 새로고침 한 번과 같은 모습으로 실제 계정에서도 볼 수 있는 알림, 할당량, 기기, 비용 요약 행을 보여 줍니다.
