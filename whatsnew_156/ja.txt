このバージョンでは、Codex の推定コストが高くなり、Claude の推定値も変わります。使用量を集計して料金を計算するのは Mac の CLI Pulse なので、iPhone のほとんどの数値は、Mac がこのバージョンにアップデートして同期した後に変わります。

・Codex の推定コストが高くなります。これまで含まれていなかったサブエージェントのセッションも数えるようになりました。また、各リクエストを、そのモデルについて OpenAI がリクエスト当日に公開していた API 料金で計算します。料金の改定は改定日から適用され、gpt-5.5 や gpt-5.6-sol などの新しいモデルは、gpt-5.4 の料金ではなくそれぞれの料金で計算されます。

・過去の Codex の使用量を新しいルールで数え直します。Mac の CLI Pulse に古いログの読み取りを許可している場合、同期済みの過去の日の Codex の使用量を数え直すため、使用状況ダッシュボードの過去の日にも新しい数値が表示されます。ログが削除された日など、元の数値のままの日もあります。

・使用状況ダッシュボードで、Codex のキャッシュ入力を 1 回だけ数えるようになりました。キャッシュ入力はもともと Codex の入力に含まれているのに二重に加算されていたため、ダッシュボードの Codex のトークン合計は、どの日も実際より多くなっていました。コストには影響しません。

・直近 30 日の Claude の推定コストも、モデルによって下がることも上がることもあります。Mac の CLI Pulse が、Anthropic がその日に公開していた料金で Claude を計算し、Claude Opus 5.5、Claude Fable 5.1、Claude Sonnet 5.5 にはそれぞれの料金を適用し、各応答の出力をすべて数えるようになったためです。

・「デモを試す」は、実際の 1 回の更新と同じ状態を表示するようになりました。アラート、クォータ、デバイス、コスト概要は実際のアカウントにもありうる内容で、コスト概要の各行の合計は総額と一致します。

・プロバイダー全体の「クォータ」バーは、ほかのバーと同じく残りの割合で表示されるようになりました。
