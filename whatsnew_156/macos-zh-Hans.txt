Codex 的费用预估变高了，Claude 的预估有所变化，「设置 › 高级」也不再要求这台 Mac 已同步到账户。

• Codex 的费用预估变高了。子 Agent 会话现在也会计入，之前它们被漏掉了。同一个 Codex 对话被拆分到两个文件中时，不会再漏算其中一个文件；子 Agent 从父会话复制过来的历史不会被重复计入。从其他会话分叉出来的会话和部分子 Agent 会话仍按简化规则计算，所以复制过来的最后一个请求可能会被计入两次。在「会话」中，正在运行的 Codex 子 Agent 现在单独显示为一个会话。

• 每个 Codex 请求按请求当天 OpenAI 公布的该模型 API 价格计算；如果 OpenAI 为该模型列出了长上下文价格，输入超过 272K token 的请求按长上下文价格计算。价格调整从生效之日起适用，较新的模型也按各自的价格计算，不再沿用 gpt-5.4 的价格：gpt-5.5、gpt-5.6-sol 等模型的价格更高，gpt-5.6-luna 等模型则更低。

• 如果某个模型还没有自己的价格而按同系列模型的单价计算，包含它的数字现在显示为「≈$…」，费用卡片上也会显示「近似」徽章。

• 较早的 Codex 数据会重新统计。如果你允许 CLI Pulse 读取更早的日志，它会再次读取最多一年的 Codex 日志，按新规则重新统计用量历史中较早的日子；登录状态下，它还会更新账户中这台 Mac 较早的 Codex 数字，让 iPhone 也显示新的数字。每当 CLI Pulse 的更新改变了 Codex 用量的统计方式，它都会再这样做一次，读取前的确认界面和「设置 › 隐私」现在也写明了这一点。日志已不存在的日子会保留原来的数字。

• 用量仪表盘现在只计一次 Codex 的缓存输入。缓存输入本就包含在 Codex 的输入里，之前却被重复计入，导致仪表盘中的 Codex token 总数偏高。如果这台 Mac 之前已有 Codex 用量，概览上会出现一张卡片说明有哪些变化；只要还有日子的数字仍按旧方式统计，仪表盘就会注明这类数字截至哪一天。

• 最近 30 天的 Claude 费用预估也有所变化：CLI Pulse 现在按 Anthropic 公布的当日价格为 Claude 计价，Claude Opus 5.5、Claude Fable 5.1 和 Claude Sonnet 5.5 改用各自的价格，1 小时缓存写入按其专属价格计算，Sonnet 5 按现行价格计算，并且每个回复只按最后一行计一次，所以有些模型的预估会降低，有些会升高。

• 更新后，第一次刷新会把最近 30 天的 Claude 和 Codex 日志重新读取一次，按新方式统计。

• 现在，「设置 › 高级」在本地模式下、以及这台 Mac 尚未同步到账户时也会显示，其中包括后台同步及其状态、「CLI 工具访问」和「隐藏个人信息」；在本地模式下，它会说明不会上传任何数据。退出登录后，这里显示「登录时打开」和后台同步；后台同步开启时，状态显示「已暂停：未登录」。关闭后台同步后，不再显示过时的状态。

• Gemini：服务商设置中不再提供无法使用的 Google 登录；Gemini CLI 的登录过期时，现在显示「会话已过期（请重新登录）」，不再让你通过 CLI Pulse 重新连接。

• 修复：在已同步到账户的 Mac 上，钥匙串锁定时的刷新不会再把这台 Mac 的用量额外发送一份（iPhone 之前会把它算两次）；服务商的总「配额」进度条显示剩余的比例。
