本版本中 Codex 的費用預估變高了，Claude 的預估也有所變化。用量是由 Mac 上的 CLI Pulse 統計並計價，所以 iPhone 上大部分的數字會在你的 Mac 安裝本版本並同步後改變。

• Codex 的費用預估變高了。Codex 的子代理工作階段現在也會計入，先前這些工作階段被遺漏。每個請求現在依請求當天 OpenAI 公布的該模型 API 價格計算。價格調整自生效日起適用，較新的模型也依各自的價格計算，不再沿用 gpt-5.4 的價格：gpt-5.5、gpt-5.6-sol 等模型的價格更高，gpt-5.6-luna 等模型則更低。

• 較早的 Codex 資料會依新規則重新統計。如果你允許 Mac 上的 CLI Pulse 讀取更早的日誌，它會重新統計已同步過的較早日子的 Codex 用量，因此用量儀表板中的這些日子也會顯示新的數字。有些日子會保留原本的數字，例如日誌已被刪除的日子。

• 用量儀表板現在只計算一次 Codex 的快取輸入。快取輸入本來就包含在 Codex 的輸入中，先前卻被重複計入，導致儀表板中每一天的 Codex token 總數都偏高。費用不受影響。

• 最近 30 天的 Claude 費用預估也有所變化：Mac 上的 CLI Pulse 現在依 Anthropic 公布的當日價格為 Claude 計價，為 Claude Opus 5.5、Claude Fable 5.1 和 Claude Sonnet 5.5 採用各自的價格，並且會計入每個回覆的全部輸出，所以有些模型的預估會降低，有些會升高。

• 「試用示範模式」現在看起來就像實際重新整理一次後的樣子：其中的警示、配額、裝置和費用概覽都是真實帳號中可能出現的，費用概覽各列加起來也等於總額。

• 服務商的整體「配額」進度條現在和其他進度條一樣，顯示剩餘的比例。
