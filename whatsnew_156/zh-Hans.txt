本版本中 Codex 的费用预估变高了，Claude 的预估也有所变化。用量由 Mac 上的 CLI Pulse 统计并计价，所以 iPhone 上的大部分数字会在你的 Mac 更新到本版本并同步后改变。

• Codex 的费用预估变高了。子 Agent 会话现在也会计入，之前它们被漏掉了。每个请求现在按 OpenAI 公布的该模型在请求当天的 API 价格计算：价格调整从生效之日起适用，gpt-5.5、gpt-5.6-sol 等较新的模型也按各自的价格计算，不再沿用 gpt-5.4 的价格。

• 较早的 Codex 数据会按新规则重新统计。如果你允许 Mac 上的 CLI Pulse 读取更早的日志，它会重新统计已经同步过的较早日子的 Codex 用量，用量仪表盘中较早的日子也会显示新的数字。有些日子会保留原来的数字，例如日志已被删除的日子。

• 用量仪表盘现在只计一次 Codex 的缓存输入。缓存输入本就包含在 Codex 的输入里，之前却被重复计入，导致这里每一天的 Codex token 总数都偏高。费用不受影响。

• 最近 30 天的 Claude 费用预估也有所变化：Mac 上的 CLI Pulse 现在按 Anthropic 当天公布的价格为 Claude 计价，Claude Opus 5.5、Claude Fable 5.1 和 Claude Sonnet 5.5 也有了各自的价格，并且会计入每个回复的全部输出，所以有些模型的预估会降低，有些会升高。

• 「试用演示」现在就像一次真实的刷新：其中的告警、配额、设备和费用概览都是真实账户可能出现的，费用概览各行加起来也等于总额。

• 服务商的总「配额」进度条现在和其他进度条一样，显示剩余的比例。
