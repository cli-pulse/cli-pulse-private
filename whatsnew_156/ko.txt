이번 버전에서는 Codex 추정 비용이 높아지고 Claude 추정치도 달라집니다. Mac의 CLI Pulse가 사용량을 집계하고 비용을 계산하므로, iPhone의 수치 대부분은 Mac이 이 버전으로 업데이트되어 동기화한 뒤에 바뀝니다.

• Codex 추정 비용이 높아집니다. 이전에는 빠져 있던 하위 에이전트 세션도 이제 집계합니다. 또한 각 요청을 해당 모델에 대해 OpenAI가 요청 당일에 공개한 API 요금으로 계산합니다. 요금 변경은 변경일부터 적용되고, gpt-5.5, gpt-5.6-sol 같은 새 모델은 gpt-5.4의 요금이 아니라 각자의 요금으로 계산됩니다.

• 지난 Codex 사용량을 새 규칙으로 다시 집계합니다. Mac의 CLI Pulse에 이전 로그 읽기를 허용했다면 이미 동기화한 지난 날짜의 Codex 사용량을 다시 집계하므로, 사용량 대시보드의 지난 날짜에도 새 수치가 표시됩니다. 로그가 삭제된 날처럼 기존 수치가 그대로 남는 날도 있습니다.

• 사용량 대시보드는 이제 Codex의 캐시 입력을 한 번만 집계합니다. 캐시 입력은 원래 Codex 입력에 포함되는데 그동안 한 번 더 더해졌습니다. 그래서 여기의 Codex 토큰 합계가 모든 날짜에서 실제보다 많게 표시되었습니다. 비용에는 영향이 없습니다.

• Mac의 CLI Pulse가 이제 Anthropic이 해당 날짜에 공개한 요금으로 Claude를 계산하고, Claude Opus 5.5, Claude Fable 5.1, Claude Sonnet 5.5에는 각자의 요금을 적용하며, 각 응답의 전체 출력을 집계하므로, 최근 30일의 Claude 추정 비용도 모델에 따라 내려가기도 하고 올라가기도 합니다.

• '데모 체험'은 이제 실제 새로고침 한 번과 같은 모습을 보여 줍니다. 알림, 할당량, 기기, 비용 요약은 실제 계정에서도 볼 수 있는 내용이며, 비용 요약의 각 행을 더하면 합계와 같습니다.

• 공급자 전체 '할당량' 막대는 이제 다른 막대처럼 남은 비율만큼 채워집니다.
