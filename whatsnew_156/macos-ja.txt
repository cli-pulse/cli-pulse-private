Codex の推定コストが高くなり、Claude の推定値が変わります。また、「設定 › 詳細」は、この Mac をアカウントと同期していなくても表示されるようになりました。

・Codex の推定コストが高くなります。これまで含まれていなかったサブエージェントのセッションも数えるようになりました。2 つのファイルに分かれた Codex のスレッドで片方が抜け落ちることはなくなり、サブエージェントが親セッションからコピーした履歴は重ねて数えません。フォークしたセッションと一部のサブエージェントのセッションは簡略化したルールで数えるため、コピーされた最後のリクエストが二重に数えられることがあります。「セッション」では、実行中の Codex のサブエージェントが個別のセッションとして表示されるようになりました。

・Codex の各リクエストの料金は、リクエスト当日に OpenAI が公開していたそのモデルの API 料金で計算するようになりました。OpenAI がロングコンテキストの料金を公開しているモデルでは、入力が 272K トークンを超えるリクエストにその料金を適用します。料金の改定は改定日から適用されます。新しいモデルは gpt-5.4 の料金ではなくそれぞれの料金で計算され、gpt-5.5 や gpt-5.6-sol などは高く、gpt-5.6-luna などは低くなります。

・まだ独自の料金がないため同系列モデルの単価で計算したモデルを含む数値は「≈$…」と表示されるようになり、コストのカードには「近似」バッジが表示されます。

・過去の Codex の使用量を数え直します。古いログの読み取りを許可している場合、CLI Pulse は最大 1 年分の Codex のログをもう一度読み取り、使用履歴の過去の日を新しいルールで数え直します。サインイン中は、アカウントにあるこの Mac の過去の Codex の数値も更新するため、iPhone にも新しい数値が表示されます。アップデートで Codex の使用量の数え方が変わるたびにこの処理を再び行うことは、確認画面と「設定 › プライバシー」にも記載されています。ログがなくなった日は元の数値のままです。

・使用状況ダッシュボードで、Codex のキャッシュ入力を 1 回だけ数えるようになりました。キャッシュ入力はもともと Codex の入力に含まれているのに二重に加算されていたため、ダッシュボードの Codex のトークン合計は実際より多くなっていました。この Mac に以前から Codex の使用量がある場合は、概要に変更点を説明するカードが表示されます。以前の方法で数えた日が残っている間は、それがどの日までかがダッシュボードに表示されます。

・直近 30 日の Claude の推定コストも変わり、モデルによって下がることも上がることもあります。CLI Pulse が、利用日に Anthropic が公開していた料金で Claude を計算し、Claude Opus 5.5、Claude Fable 5.1、Claude Sonnet 5.5 にはそれぞれの料金を、1 時間のキャッシュ書き込みには専用の料金を、Sonnet 5 には現行の料金を適用し、各応答を最後の行に基づいて 1 回だけ数えるようになったためです。

・アップデート後の最初の更新では、直近 30 日分の Claude と Codex のログを一度読み直し、新しい方法で数えます。

・「設定 › 詳細」は、ローカルモードのときや、この Mac をまだアカウントと同期していないときにも表示されるようになり、バックグラウンド同期とその状態、「CLI ツールアクセス」、「個人情報を非表示」が含まれます。ローカルモードでは、何もアップロードしないことが表示されます。サインアウト中は「ログイン時に起動」とバックグラウンド同期が表示され、バックグラウンド同期がオンなら状態は「一時停止中：サインアウト中」になります。バックグラウンド同期がオフのときは、古い状態を表示しなくなりました。

・Gemini：プロバイダーの設定に、使えない Google サインインを表示しなくなりました。Gemini CLI のログインの有効期限が切れたときは、CLI Pulse で接続し直すよう求めるのではなく、「セッションの有効期限切れ（再度サインインしてください）」と表示します。

・修正：アカウントと同期している Mac で、キーチェーンがロックされているときに更新しても、この Mac の使用量を重複して送信しなくなりました（iPhone ではそれが二重に数えられていました）。プロバイダー全体の「クォータ」バーは残りの割合で表示されます。「デモを試す」は実際に 1 回更新したときと同じ状態になり、アラート、クォータ、デバイス、コスト概要の各行は、実際のアカウントにもありうる内容になりました。
