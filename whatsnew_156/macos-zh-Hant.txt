Codex 的費用預估變高了，Claude 的預估有所變化，「設定 › 進階」也不再需要這台 Mac 已同步到帳號。

• Codex 的費用預估變高了。Codex 的子代理工作階段現在也會計入，先前這些工作階段被遺漏。同一個 Codex 對話被拆分到兩個檔案中時，不會再漏算其中一個檔案；子代理從上層工作階段複製過來的歷史不會被重複計入。從其他工作階段分叉出來的工作階段和部分子代理工作階段仍依簡化規則計算，所以複製過來的最後一個請求可能會被計入兩次。在「工作階段」中，正在執行的 Codex 子代理現在會單獨顯示為一個工作階段。

• 每個 Codex 請求依請求當天 OpenAI 公布的該模型 API 價格計算；如果 OpenAI 為該模型列出了長上下文價格，輸入超過 272K token 的請求會依長上下文價格計算。價格調整自生效日起適用，較新的模型也依各自的價格計算，不再沿用 gpt-5.4 的價格：gpt-5.5、gpt-5.6-sol 等模型的價格更高，gpt-5.6-luna 等模型則更低。

• 如果某個模型還沒有自己的價格而依同系列模型的單價計算，包含它的數字現在會顯示為「≈$…」，費用卡片上也會顯示「近似」徽章。

• 較早的 Codex 資料會重新統計。如果你允許 CLI Pulse 讀取更早的日誌，它會再次讀取最多一年份的 Codex 日誌，依新規則重新統計用量歷史中較早的日子；登入狀態下，它還會更新帳號中這台 Mac 較早的 Codex 數字，讓 iPhone 也顯示新的數字。每當 CLI Pulse 的更新改變了 Codex 用量的統計方式，它都會再這樣做一次，讀取前的確認畫面和「設定 › 隱私」現在也寫明了這一點。日誌已不存在的日子會保留原本的數字。

• 用量儀表板現在只計算一次 Codex 的快取輸入。快取輸入本來就包含在 Codex 的輸入中，先前卻被重複計入，導致儀表板中的 Codex token 總數偏高。如果這台 Mac 先前已有 Codex 用量，概覽上會出現一張卡片說明有哪些變化；只要還有日子的數字仍依舊方式統計，儀表板就會註明這類數字截至哪一天。

• 最近 30 天的 Claude 費用預估也有所變化：CLI Pulse 現在依 Anthropic 公布的當日價格為 Claude 計價，Claude Opus 5.5、Claude Fable 5.1 和 Claude Sonnet 5.5 改用各自的價格，1 小時快取寫入依其專屬價格計算，Sonnet 5 依現行價格計算，並且每個回覆只依最後一行計算一次，所以有些模型的預估會降低，有些會升高。

• 更新後，第一次重新整理會把最近 30 天的 Claude 和 Codex 日誌重新讀取一次，依新方式統計。

• 現在，「設定 › 進階」在本機模式下、以及這台 Mac 尚未同步到帳號時也會顯示，其中包括背景同步及其狀態、「CLI 工具存取權限」和「隱藏個人資訊」；在本機模式下，它會說明不會上傳任何資料。登出後，這裡會顯示「登入時自動啟動」和背景同步；背景同步開啟時，狀態會顯示「已暫停：已登出」。關閉背景同步後，不再顯示過時的狀態。

• Gemini：服務商設定中不再提供無法使用的 Google 登入；Gemini CLI 的登入過期時，現在會顯示「工作階段已過期（請重新登入）」，不再要你透過 CLI Pulse 重新連線。

• 修正：在已同步到帳號的 Mac 上，鑰匙圈鎖定時的重新整理不會再把這台 Mac 的用量額外傳送一份（iPhone 先前會把它算兩次）；服務商的整體「配額」進度條顯示剩餘的比例；「試用示範模式」看起來就像實際重新整理一次後的樣子，其中的警示、配額、裝置和費用概覽各列都是真實帳號中可能出現的。
