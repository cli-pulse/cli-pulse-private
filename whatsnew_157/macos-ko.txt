공급자 카드에 이제 '오늘', '이번 주', '30일'이 표시되고, 옆의 작은 차트를 클릭하면 해당 공급자의 사용 기록이 열립니다. Codex 카드에는 한도 리셋권도 표시할 수 있습니다.

• 각 공급자 카드에 '오늘', '이번 주', '30일'이 각각 토큰 수 및 추정 비용과 함께 표시되고, 그 옆에 더 작아진 30일 차트가 있습니다. 차트를 클릭하면 해당 공급자의 '사용 기록'이 열립니다. 로그아웃 상태에서는 이 Mac의 세션 로그를 집계하며('이 Mac'), CLI Pulse가 로그를 읽으려면 설정 › 고급 › CLI 도구 접근에서 허용해야 합니다. 로그인 상태에서는 날짜마다 이 Mac과 계정 중 더 큰 값을 표시합니다('모든 기기').

• '사용 기록'은 한 공급자의 최근 30일을 날짜별, 모델별로 보여 줍니다. '토큰'과 '비용' 사이에서 전환할 수 있고, 날짜를 클릭하면 그날의 모델과 각 모델의 토큰 수 및 추정 비용이 표시됩니다. 양쪽 모두에 사용량이 있으면 '이 Mac'과 '모든 기기' 중에서 고를 수 있습니다. 카드의 차트나 사용량 대시보드의 '공급자별'에서 열 수 있습니다.

• 사용량 대시보드의 '추세' 차트에서도 이제 '토큰'과 '비용' 사이에서 전환할 수 있으며, 대시보드는 열려 있는 동안에도 업데이트됩니다. 이전에는 열었을 때의 수치를 그대로 유지했습니다.

• 필요 없는 카드 항목을 숨길 수 있습니다. 공급자 카드를 오른쪽 클릭해 '카드에 표시'에서 선택하거나 설정 › 공급자를 사용하세요. '모든 섹션 표시'로 다시 표시할 수 있습니다. 새로고침과 알림은 그대로 동작합니다.

• 한도 리셋권: Codex에 로그인된 ChatGPT 계정에 Codex 사용 한도를 리셋할 수 있는 이용권이 있으면, Codex 카드에 사용 가능한 개수와 각각의 만료 시간이 표시됩니다. CLI Pulse는 표시만 하며 사용하지 않습니다. Codex가 ~/.codex에 저장한 로그인 정보로 OpenAI에 조회하므로 이 폴더에 대한 접근 권한이 필요합니다. 카드에서 '~/.codex 접근 허용'을 선택하거나 설정 › 고급 › CLI 도구 접근에서 허용하세요.

• '공급자' 탭의 비용 막대와 '개요'의 '오늘'은 이제 카드 값을 합산한 값이므로, 같은 계정을 두 대의 Mac에서 사용해도 카드보다 적게 표시되지 않습니다.

• Crof, Kimi K2, CrossModel은 더 이상 지원하지 않습니다. Crof는 서비스를 종료했고, CLI Pulse는 Kimi K2와 CrossModel의 운영 주체를 확인할 수 없어 더 이상 두 서비스에 연결하지 않으며 키도 보내지 않습니다. Kimi K2나 CrossModel에 키를 설정한 적이 있다면 알림이 한 번 표시됩니다. Kimi와 Moonshot은 계속 지원됩니다.

• 로그인 토큰, API 키, 쿠키를 더 이상 CLI Pulse와 헬퍼의 네트워크 캐시에 저장하지 않습니다. 이 버전을 처음 실행할 때 해당 캐시를 한 번 비웁니다.

• '연동'에서 더 이상 '장시간 세션'을 Webhook 이벤트로 제공하지 않습니다. CLI Pulse가 이 알림을 보내지 않기 때문입니다.
