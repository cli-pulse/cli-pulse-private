服務商卡片現在顯示「今日」「本週」和「30 天」，按一下旁邊的小圖表即可開啟該服務商的用量歷史；Codex 卡片也能顯示你的限額重置券。

• 每張服務商卡片顯示「今日」「本週」和「30 天」，各含 token 數和預估費用，旁邊是一張較小的 30 天圖表。按一下圖表即可開啟該服務商的「用量歷史」。未登入時，卡片統計這台 Mac 上的工作階段日誌（「這台 Mac」），需要先在「設定 › 進階 › CLI 工具存取權限」中允許 CLI Pulse 讀取這些日誌；登入後，每一天取這台 Mac 與帳號中較高的數字（「所有裝置」）。

• 「用量歷史」依天和模型顯示一個服務商最近 30 天的用量。可在「token」和「費用」之間切換；按一下某一天，即可列出當天的模型及其 token 數和預估費用；兩邊都有用量時，還可以在「這台 Mac」和「所有裝置」之間選擇。可從卡片的圖表或「用量儀表板」的「依服務商」開啟。

• 「用量儀表板」的「趨勢」圖表現在也可以在「token」和「費用」之間切換，儀表板在開啟期間也會更新；先前它一直顯示開啟時的數字。

• 隱藏卡片上不需要的部分：在服務商卡片上按右鍵，在「在卡片上顯示」下選擇，或前往「設定 › 服務商」。「顯示全部區塊」可讓它們重新顯示。重新整理和警示照常進行。

• 限額重置券：如果 Codex 所登入的 ChatGPT 帳號有可重置 Codex 用量限額的重置券，Codex 卡片會顯示可用張數和每張的到期時間。CLI Pulse 只會顯示，從不使用。它會用 Codex 儲存在 ~/.codex 中的登入資訊向 OpenAI 查詢，因此需要該資料夾的存取權限：在卡片上選擇「授權存取 ~/.codex」，或在「設定 › 進階 › CLI 工具存取權限」中授權。

• 「服務商」分頁費用列和「概覽」中的「今日」現在是各張卡片的總和，因此同一個帳號在兩台 Mac 上使用時，這兩處的數字不會再低於卡片。

• 不再支援 Crof、Kimi K2 和 CrossModel。Crof 已停止服務，CLI Pulse 也無法確認 Kimi K2 和 CrossModel 由誰營運，因此不再連線到它們，也不再向它們傳送你的金鑰。如果你曾為 Kimi K2 或 CrossModel 設定過金鑰，會看到一次性的通知。Kimi 和 Moonshot 仍受支援。

• 登入權杖、API 金鑰和 Cookie 不再儲存在 CLI Pulse 及其 helper 的網路快取中。首次啟動此版本時，會把該快取清空一次。

• 「整合」不再提供「工作階段過長」這個 Webhook 事件，因為 CLI Pulse 不會發出這則警示。
