服务商卡片现在显示「今日」「本周」和「30 天」，点按旁边的小图表即可打开该服务商的用量历史；Codex 卡片还能显示你的限额重置券。

• 每张服务商卡片显示「今日」「本周」和「30 天」，各含 token 数和预估费用，旁边是一张更小的 30 天图表。点按图表即可打开该服务商的「用量历史」。未登录时，卡片统计这台 Mac 上的会话日志（「这台 Mac」），需要先在「设置 › 高级 › CLI 工具访问」中允许 CLI Pulse 读取这些日志；登录后，每一天取这台 Mac 与账户中较高的数字（「所有设备」）。

• 「用量历史」按天和模型显示一个服务商最近 30 天的用量。可在「token」和「费用」之间切换；点按某一天，即可列出当天的模型及其 token 数和预估费用；两边都有用量时，还可以在「这台 Mac」和「所有设备」之间选择。可从卡片的图表或「用量仪表盘」的「按服务商」打开。

• 「用量仪表盘」的「趋势」图表现在也可以在「token」和「费用」之间切换，仪表盘在打开期间也会更新；之前它一直显示打开时的数字。

• 隐藏卡片上不需要的部分：右键点按服务商卡片，在「在卡片上显示」下选择，或前往「设置 › 服务商」。「显示全部区块」可让它们重新显示。刷新和告警照常进行。

• 限额重置券：如果 Codex 所登录的 ChatGPT 账户有可重置 Codex 用量限额的重置券，Codex 卡片会显示可用张数和每张的到期时间。CLI Pulse 只显示，从不使用。它会用 Codex 保存在 ~/.codex 中的登录信息向 OpenAI 查询，因此需要该文件夹的访问权限：在卡片上选择「授权访问 ~/.codex」，或在「设置 › 高级 › CLI 工具访问」中授权。

• 「服务商」标签页费用栏和「概览」中的「今日」现在是各张卡片的合计，因此同一账户在两台 Mac 上使用时，这两处的数字不会再低于卡片。

• 不再支持 Crof、Kimi K2 和 CrossModel。Crof 已停止服务，CLI Pulse 也无法确认 Kimi K2 和 CrossModel 由谁运营，因此不再连接它们，也不再向它们发送你的密钥。如果你曾为 Kimi K2 或 CrossModel 设置过密钥，会看到一次性的通知。Kimi 和 Moonshot 仍受支持。

• 登录令牌、API 密钥和 Cookie 不再存储在 CLI Pulse 及其 helper 的网络缓存中。首次启动本版本时，会把该缓存清空一次。

• 「集成」不再提供「会话时间过长」这一 Webhook 事件，因为 CLI Pulse 不会发出这条告警。
