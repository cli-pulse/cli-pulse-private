MiniMax のクォータがカードに表示されるようになり、MiniMax の中国本土向けプラットフォームの API キーも使えるようになりました。

• MiniMax: CLI Pulse が、MiniMax が現在返すクォータ情報を読み取れるようになりました。カードには、プランの利用期間（5 時間、日次、またはプランに応じた期間）と、プランにある場合は週次の期間が、残りの割合で、それぞれのリセット時刻とともに表示されます。これまでこれらのアカウントは「不明」と表示されていました。

• MiniMax: MiniMax の中国本土向けプラットフォームで作成した API キーが使えるようになりました。CLI Pulse はまず MiniMax のグローバルサービスを試し、グローバル側がキーを拒否した場合にだけ中国本土のサービスを試して、キーを受け付けた方を記憶します。
