로컬 모드에서 이 Mac의 로그에 사용량이 있는 공급자의 카드가 표시되고, Claude 카드는 Claude가 준비되지 않은 이유를 알려 주며, 느린 네트워크에서 응답이 멈추는 문제가 수정되었습니다.

• 로컬 모드: 이 Mac의 세션 로그에 최근 7일간의 Claude Code 또는 Codex 사용량이 있으면, 공급자를 설정하지 않았더라도 '공급자' 탭에 해당 공급자의 카드가, '공급자 사용량'에 행이 토큰 수 및 추정 비용과 함께 표시됩니다. 준비되지 않은 경우 카드에 그 이유가 표시됩니다. 사용을 끈 공급자는 로그가 있어도 카드가 생기지 않습니다.

• 로컬 모드: CLI Pulse가 로그 접근을 기다리는 동안이나 로그에 사용량이 있을 때 'AI 도구가 감지되지 않았습니다'가 더 이상 표시되지 않습니다. 로컬 스캔 질문에서 '지금은 안 함'을 선택하면, 이 Mac의 사용 데이터를 수집하고 있다는 '로컬 모드' 카드가 '개요'에 더 이상 표시되지 않습니다.

• CLI Pulse가 AI 도구 로그를 읽을 수 없을 때 '공급자' 탭에도 '개요'와 같은 배너가 표시됩니다. '허용'을 클릭하고 홈 폴더 접근을 허용하면 CLI Pulse가 바로 로그를 다시 읽습니다. 이전에는 설정으로 이동해야 했습니다.

• Claude 카드가 이제 Claude가 준비되지 않은 이유를 알려 줍니다. 예를 들어 '로그인되지 않음', '엄격한 개인정보 보호 모드에서는 읽지 않음', '키체인 접근 거부됨' 등입니다. 이전에는 이런 경우에도 '설정되지 않음'으로 표시되었습니다.

• CLI Pulse가 키체인에서 Claude Code 로그인 정보를 읽도록 허용할지 묻는 macOS 요청을 거부하면, CLI Pulse는 이제 30분 후에 다시 시도합니다. 이전에는 새로고침할 때마다 macOS가 다시 물었습니다. 더 이상 묻지 않게 하려면 설정 › 개인정보 보호에서 'Claude Code 키체인 접근 건너뛰기'를 켜세요.

• 느린 네트워크에서 CLI Pulse가 이 Mac의 호스트 이름을 확인하는 동안 응답하지 않을 수 있던 문제를 수정했습니다. 이제 이 작업은 백그라운드에서 수행됩니다.
