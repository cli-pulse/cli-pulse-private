本地模式下，这台 Mac 的日志中有用量的服务商现在会有自己的卡片；Claude 卡片会说明 Claude 未就绪的原因；网络较慢时无响应的问题也已修复。

• 本地模式：这台 Mac 的会话日志中有最近 7 天的 Claude Code 或 Codex 用量时，即使该服务商尚未配置，「服务商」标签页中也会出现它的卡片，显示 token 数和预估费用；当天用过它时，「服务商用量」中也会出现一行。如果它尚未就绪，卡片会说明原因。你关闭的服务商不会因为日志而出现卡片。

• 本地模式：在 CLI Pulse 等待日志的访问权限时，或日志中已有用量时，不再显示「未检测到 AI 工具」。在本地扫描的询问中选择「暂时不要」后，「概览」不再显示提示这台 Mac 正在采集用量的「本地模式」卡片。

• CLI Pulse 无法读取 AI 工具的日志时，「服务商」标签页现在也会显示与「概览」相同的横幅：点按「授权」并允许访问你的个人文件夹，CLI Pulse 会立即重新读取日志。以前这个标签页会把你带到「设置」。

• Claude 卡片现在会说明 Claude 未就绪的原因，例如「未登录」「严格隐私模式下不读取」或「已拒绝钥匙串访问」；以前这些情况都显示「未配置」。

• 如果你在 macOS 询问时拒绝让 CLI Pulse 从钥匙串读取你的 Claude Code 登录信息，CLI Pulse 现在会等 30 分钟再重试，而不是每次刷新都让 macOS 询问。如果不想再被询问，请在「设置 › 隐私」中开启「跳过 Claude Code 钥匙串访问」。

• 修复了一个无响应问题：网络较慢时，CLI Pulse 在查询这台 Mac 的主机名时可能停止响应。现在这一步在后台进行。
