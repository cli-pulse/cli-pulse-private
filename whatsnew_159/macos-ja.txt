ローカルモードで、この Mac のログに使用量があるプロバイダーのカードが表示されるようになりました。Claude のカードには、Claude の準備ができていない理由が表示されます。また、低速なネットワークで応答しなくなる問題を修正しました。

・ローカルモード：この Mac のセッションログに過去 7 日間の Claude Code または Codex の使用量がある場合、そのプロバイダーが未設定でも、「プロバイダー」タブにカードが、「プロバイダー使用量」に行が表示され、トークン数と推定コストがわかるようになりました。準備ができていない場合は、その理由がカードに表示されます。オフにしたプロバイダーには、ログからカードは作られません。

・ローカルモード：CLI Pulse がログへのアクセスを待っている間や、ログに使用量がある場合に、「AI ツールが検出されませんでした」と表示されなくなりました。ローカルスキャンの確認で「今はしない」を選んだ後は、この Mac の使用状況を収集中だと伝える「ローカルモード」のカードが「概要」に表示されなくなりました。

・CLI Pulse が AI ツールのログを読み取れないとき、「プロバイダー」タブにも「概要」と同じバナーが表示されるようになりました。「許可」をクリックしてホームフォルダへのアクセスを許可すると、CLI Pulse がすぐにログを読み直します。これまでは「設定」に移動する必要がありました。

・Claude のカードに、Claude の準備ができていない理由が表示されるようになりました。たとえば「未サインイン」「プライバシー強化モード中は読み取りません」「キーチェーンへのアクセスが拒否されました」などです。これまではこうした場合も「未設定」と表示されていました。

・CLI Pulse がキーチェーンから Claude Code のログイン情報を読み取ることを macOS の確認で拒否した場合、CLI Pulse は 30 分待ってから再試行するようになりました。これまでは更新のたびに macOS が確認していました。確認を表示しないようにするには、「設定 › プライバシー」で「Claude Code のキーチェーンにアクセスしない」をオンにしてください。

・低速なネットワークで、CLI Pulse がこの Mac のホスト名を調べている間に応答しなくなることがある問題を修正しました。この処理はバックグラウンドで行うようになりました。
