本機模式下，這台 Mac 的日誌中有用量的服務商現在會有自己的卡片；Claude 卡片會說明 Claude 未就緒的原因；網路較慢時沒有回應的問題也已修正。

• 本機模式：這台 Mac 的工作階段日誌中有最近 7 天的 Claude Code 或 Codex 用量時，即使該服務商尚未設定，「服務商」分頁中也會出現它的卡片，「服務商用量」中也會出現一列，顯示 token 數與預估費用。如果它尚未就緒，卡片會說明原因。你關閉的服務商不會因為日誌而出現卡片。

• 本機模式：在 CLI Pulse 等待日誌的存取權限時，或日誌中已有用量時，不再顯示「未偵測到 AI 工具」。在本機掃描的詢問中選擇「暫時不要」後，「概覽」不再顯示說這台 Mac 正在收集用量的「本機模式」卡片。

• CLI Pulse 無法讀取 AI 工具的日誌時，「服務商」分頁現在也會顯示與「概覽」相同的橫幅：按一下「授權」並允許存取你的個人專屬資料夾，CLI Pulse 會立即重新讀取日誌。先前這個分頁會把你帶到「設定」。

• Claude 卡片現在會說明 Claude 未就緒的原因，例如「未登入」「嚴格隱私模式下不讀取」或「已拒絕鑰匙圈存取」；先前這些情況都顯示「未設定」。

• 如果你在 macOS 詢問時拒絕讓 CLI Pulse 從鑰匙圈讀取你的 Claude Code 登入資訊，CLI Pulse 現在會等 30 分鐘再重試，而不是每次重新整理都讓 macOS 詢問。如果不想再被詢問，請在「設定 › 隱私」中開啟「略過 Claude Code 鑰匙圈存取」。

• 修正了一個沒有回應的問題：網路較慢時，CLI Pulse 在查詢這台 Mac 的主機名稱時可能停止回應。現在這一步改在背景進行。
