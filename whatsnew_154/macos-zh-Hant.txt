現在可以在 Mac 上選擇 CLI Pulse 提供的所有語言，而且每種語言都讀得順暢。先前在中文、日文、韓文和西班牙文介面下，App 裡仍有部分內容顯示英文，日期和數字的寫法也不符合你的語言習慣。

• 新增：語言選單（CLI Pulse 視窗底部的地球圖示）列出全部六種語言，先前缺少 한국어 和 Español。首次啟動時和登入之前也能使用；日期和數字會跟著你的選擇，macOS 系統本身的按鈕則在重新啟動 App 後才會切換。

• 翻譯：補齊了仍顯示英文的標籤和訊息。之後每種語言都作為整體重新審閱，修正了數百處錯誤或前後不一致的譯法。繁體中文改用台灣 Apple 軟體的用語，例如帳號、警示、工作階段和程序；在 macOS 14 或以上版本，韓文也不再在詞語中間換行。

• 配額狀態標籤「偏低」改為「吃緊」。它顯示在「已使用 92%」旁邊，原本讀起來像是用量偏低。

• 服務商狀態、配額名稱、方案徽章、工作階段名稱、警示和通知都以你的語言顯示，試用示範模式的範例資料和匯出的成本報告也一樣。錯誤訊息不再直接顯示伺服器的原始回應（「HTTP 403: {"code":403,…}」）。

• 日期、時間、數字和金額依照你的語言和地區顯示：時間、配額重置時間（顯示為當地時間，而非 UTC 時間戳記）、用量節奏預估、重新整理頻率（「5 分鐘」而不是「5m」）、token 數，以及西班牙文的數字和貨幣格式。

• 修正：Mac 的曆法設為日本和曆、民國紀年或佛曆時，Codex 的用量和費用顯示為 0，每日用量也以錯誤的日期上傳，因此 iPhone 上一直看不到。

• 旁白：選單列中的 CLI Pulse 會唸出數字的意思（未解決的警示、剩餘配額、離線），先前沒有名稱的開關和彈出式選單也都有了名稱。

• 配額百分比處處一致：選單列、服務商卡片和警示採用相同的計算方式，「已使用 92%」旁邊不會再出現「剩餘 7%」。

• 新增：如果這台 Mac 已從你的帳號中移除，或你的帳號已在其他裝置上同步、這台 Mac 卻從未設定，「設定」現在會提供「設定雲端同步」。先前「設定」裡沒有辦法重新設定。

• 首次啟動時，匿名安裝統計的說明不再被截斷，語言選單也會留在畫面上。「設定」、熱度圖的月份標籤和每小時圖表的標題都經過整理。

• 更名：「設定」中的「僅本機模式」改名為「嚴格隱私模式」。舊名稱讀起來像是「停止同步」，但它從來沒有這個作用。它實際的作用是讓 CLI Pulse 不再自行讀取 Claude Code 的鑰匙圈項目，並關閉匿名統計。
