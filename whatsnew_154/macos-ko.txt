이제 Mac에서도 CLI Pulse의 모든 언어를 선택할 수 있고, 어느 언어로든 자연스럽게 읽을 수 있습니다. 중국어, 일본어, 한국어, 스페인어에서는 앱 일부가 아직 영어로 표시되거나, 날짜와 숫자가 언어에 맞지 않는 형식으로 표시되었습니다.

• 신규: 언어 메뉴(CLI Pulse 창 하단의 지구본 아이콘)에 여섯 개 언어가 모두 표시됩니다. 이전에는 한국어와 Español 항목이 없었습니다. 처음 실행할 때와 로그인하기 전에도 쓸 수 있고, 날짜와 숫자도 선택한 언어를 따릅니다. macOS 자체의 버튼은 앱을 다시 시작하면 바뀝니다.

• 번역: 영어로 남아 있던 레이블과 메시지를 번역했습니다. 이어서 언어별로 전체를 검토해 잘못되었거나 일관되지 않은 표현 수백 곳을 고쳤습니다. 번체 중국어는 대만 Apple 소프트웨어의 용어를 쓰도록 바꿨고, macOS 14 이상에서는 한국어가 단어 중간에서 줄이 바뀌지 않습니다.

• 공급자 상태, 할당량 이름, 요금제 배지, 세션 이름, 알림이 사용자의 언어로 표시되며, '데모 체험'의 샘플 데이터와 내보낸 비용 보고서도 마찬가지입니다. 오류도 서버 응답('HTTP 403: {"code":403,…}')을 그대로 표시하지 않습니다.

• 날짜, 시간, 숫자, 금액이 언어와 지역에 맞게 표시됩니다. 시간, 할당량 리셋 시간(UTC 타임스탬프 대신 현지 시간), 페이스 예측, 새로고침 주기('5m' 대신 '5분'), 토큰 수, 스페인어의 숫자와 통화 표기가 여기에 해당합니다.

• 수정: 캘린더를 일본력, 대만력, 불교력으로 설정한 Mac에서 Codex 사용량과 비용이 0으로 표시되고, 일일 사용량이 잘못된 날짜로 업로드되어 iPhone에 표시되지 않던 문제를 고쳤습니다.

• VoiceOver: 메뉴 막대의 CLI Pulse가 숫자의 의미(해결되지 않은 알림, 남은 할당량, 오프라인)를 읽어 주며, 이름이 없던 스위치와 팝업 메뉴에도 이름이 생겼습니다.

• 할당량 퍼센트가 어디서나 일치합니다. 메뉴 막대, 공급자 카드, 알림이 같은 방식으로 반올림하므로 '92% 사용됨' 옆에 '7% 남음'이 표시되지 않습니다.

• 신규: 이 Mac이 계정에서 제거되었거나, 계정은 다른 기기에서 동기화하고 있는데 이 Mac은 설정한 적이 없는 경우 '설정'에 '클라우드 동기화 설정'이 표시됩니다. 이전에는 '설정'에서 다시 설정할 방법이 없었습니다.

• 처음 실행할 때 익명 설치 통계 안내가 잘리지 않고, 언어 메뉴도 화면에 남아 있습니다. '설정', 히트맵의 월 레이블, 시간별 차트의 제목도 정리했습니다.

• 이름 변경: '설정'의 '로컬 전용 모드'가 '엄격한 개인정보 보호 모드'로 바뀌었습니다. 이전 이름은 '동기화 중지'처럼 읽혔지만 그런 기능은 없었습니다. 실제로는 CLI Pulse가 Claude Code의 키체인 항목을 스스로 읽지 않게 하고 익명 통계를 끕니다.
