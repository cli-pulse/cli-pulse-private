Mac でも CLI Pulse のすべての言語を選べるようになり、どの言語でも自然に読めるようになりました。中国語、日本語、韓国語、スペイン語では、アプリの一部がまだ英語のままだったり、日付や数値の書き方が言語に合っていなかったりしました。

・新機能: 言語メニュー（CLI Pulse のウィンドウ下部にある地球のアイコン）に 6 言語すべてが並ぶようになりました。これまでは 한국어 と Español がありませんでした。初回起動時やサインイン前から使え、日付と数値も選んだ言語に従います。macOS 自体のボタンは、アプリを再起動すると切り替わります。

・翻訳: 英語のまま残っていたラベルやメッセージを翻訳しました。そのうえで言語ごとに全体を見直し、誤訳や表記の揺れを数百か所修正しました。繁体字中国語は台湾の Apple ソフトウェアの用語にそろえ、macOS 14 以降では韓国語が単語の途中で改行されなくなりました。

・プロバイダーの状態、クォータ名、プランのバッジ、セッション名、アラートと通知が、あなたの言語で表示されるようになりました。「デモを試す」のサンプルデータや、書き出したコストレポートも同じです。エラーも、サーバーの応答（「HTTP 403: {"code":403,…}」）をそのまま表示しなくなりました。

・日付、時刻、数値、金額が言語と地域に合わせて表示されます。対象は時刻、クォータのリセット時刻（UTC のタイムスタンプではなく現地時刻）、ペースの予測、更新頻度（「5m」ではなく「5分」）、トークン数、スペイン語の数値と通貨の表記です。

・修正: カレンダーを和暦、中華民国暦、仏暦に設定している Mac では、Codex の使用量とコストが 0 になり、日ごとの使用量が誤った日付でアップロードされていたため、iPhone に表示されませんでした。

・VoiceOver: メニューバーの CLI Pulse が、数字の意味（未解決のアラート、残りのクォータ、オフライン）を読み上げるようになりました。名前のなかったスイッチやポップアップメニューにも名前が付きました。

・クォータのパーセンテージがどこでも一致するようになりました。メニューバー、プロバイダーのカード、アラートの丸め方がそろい、「92% 使用済み」の横に「残り 7%」と表示されることはなくなりました。

・新機能: この Mac がアカウントから削除された場合や、アカウントは別のデバイスで同期しているのにこの Mac がまだセットアップされていない場合に、「設定」に「クラウド同期をセットアップ」が表示されるようになりました。これまでは「設定」から再びセットアップする方法がありませんでした。

・初回起動時に匿名インストール統計のお知らせが途中で切れなくなり、言語メニューも画面内に収まるようになりました。「設定」、ヒートマップの月のラベル、時間別グラフの見出しも整えました。

・名称変更: 「設定」の「ローカルのみモード」は「プライバシー強化モード」になりました。旧名称は「同期を止める」という意味に読めましたが、そうした働きはありません。実際には、CLI Pulse が Claude Code のキーチェーン項目を自動で読み取らないようにし、匿名の統計情報の送信をオフにします。
